# yerminal

Lightweight cross-platform desktop terminal workspace for developers running multiple AI coding agents.

## Planned stack
Rust · Tauri 2 · React · TypeScript · xterm.js · portable-pty · git2 · react-resizable-panels

## Development
The implementation plan is in [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md). Rust/Cargo must be installed to run the Tauri application. Windows 11 is the primary target; Linux and macOS remain explicit validation targets.
